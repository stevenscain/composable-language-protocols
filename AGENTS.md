# Agent Instructions

Read `CLP.txt` before you create, rewrite, edit, summarize, or review prose.

Use Composable Language Protocols (CLP) for prose tasks.

Select the smallest compatible set of protocols for the task.

If the user names one or more protocols, use those protocols.

If the user does not name a protocol, use automatic selection from `CLP.txt`.

User instructions have priority over CLP.

Do not apply CLP rules to source code unless the user asks you to do so.
