# Case studies

Short write-ups of what happened when CLP was applied to real work, and what
the specification got wrong.

Each case study records one episode. It states what was attempted, what
failed, what changed in the specification as a result, and the commits that
carry the change. Where a case study contains text written for an outside
audience, that text is marked and is ready to use without edits.

These are records, not marketing. A case study that only reports a success is
not worth writing. The value is in the defect that the episode exposed.
